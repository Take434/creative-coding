# Creative Coding
This is my creative coding project for the "Generative Systeme" Module during the SoSe 26 at the HSRW.  
The project is hosted live under https://creative-coding.t-herr.com/ using github pages.

# Running Locally
You need pnpm to run the project (https://pnpm.io/installation).  
Then install the packages and run the dev script.
```
pnpm i
pnpm dev
```
